事業者状況登録システム(Spring Boot ＋ JPA 使用版)の使い方

名前、業種、詳細を入れて登録ボタンを押す。
業種には Bus か FC を入れる(大文字小文字もこの通りに)。
業種が Bus のときは、詳細に利用者数を入れる。
業種が FC のときは、詳細に店の一覧を入れる。
店と店の間は半角空白で区切る。全角空白は不可。
空白は複数並んでてもよい。

すべての登録が完了したら、
登録状況表示ボタンを押して登録事業所一覧画面を表示し、
登録状況を確認する。

URL は http://localhost/ページ名。
(RegDepStBootJPA.bat で起動した場合は http://localhost/Ex10 のウィンドウが自動で開かれる)

ページ名は、
Ex10　‥‥‥‥‥‥‥‥‥‥‥ DBに保存版。
Ex10_pr1 ～ Ex10_pr2 ‥‥‥ DBに保存版(排他制御確認のために登録処理を遅くしてある。
　　　　　　　　　　　　　　　　　　　　　　Bus: 利用者数ｍ秒遅延。FC: 3000ｍ秒遅延)。

これを動かすには、事前にMySQLのインストールと設定をしておく必要がある。

具体的には、事前に以下のことを行っておく。

(1) MySQLをインストール。
(2) ユーザ名 root 、パスワード pass というアカウントを作成。
(3) MySQLのコンソールで以下のSQL文を実行。
create database edu_sample;
use edu_sample;
create table dep_status(id int auto_increment primary key,
  name varchar(20), type varchar(10), shared varchar(20));
